The cost strip keeps the Choir's health and this month's savings in view on every screen.

- `hg-strip` with `hg-strip__item`s, `hg-dots`, separators, `hg-strip__spent` and `hg-strip__saved` (pushed right).
- Expanded and wide: in the sidebar footer. Medium: under the prompt bar. Compact: under the prompt bar, two items only (voices and saved).
- Consumer provides counts and amounts; amounts always carry "saved" or "spent".
