Device cards describe one voice in the Choir; the orbit diagram shows them all.

- `hg-card hg-device` > head (glyph, name, address in mono, mode status), three `hg-spec`s (GPU, VRAM, RAM), a load `hg-meter`, a footer with availability.
- Add `hg-card--live` while the device runs a job (gold halo) and `hg-meter--live` for its load bar.
- Opportunistic devices show when they are likely free ("free ~11:40 pm"); server devices say "Always available".
- The Choir diagram puts this device at the centre in `brand`, others on silver orbits; running devices carry a gold halo, queued ones a dashed sapphire ring.
