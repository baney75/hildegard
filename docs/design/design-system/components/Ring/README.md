Rings are Hildegard's progress and loading indicator: concentric circles from the Scivias.

- Outer gold ring = the job; inner green ring = the device working; gold core = the Living Light.
- Indeterminate: add `hg-ring--busy`. Determinate: set `stroke-dasharray`/`stroke-dashoffset` on `.bar` and expose `aria-valuenow`.
- Sizes via `--size`: 24px inline, 40–48px in rows and the tray, 72px+ for a hero render.
- Always pair with a label nearby; the ring alone is decoration to a screen reader. Spins stop under reduced motion.
