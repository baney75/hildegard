The tray popover is Hildegard's menu bar and system tray presence on every desktop OS.

- `hg-tray` (360px): head with mark and this device's mode, the job it runs with a ring, the Lend compute `hg-switch`, and this month's savings.
- macOS uses `tray-template.svg` as a template image; Windows and Linux use `tray-light.svg` on dark bars.
- The switch pauses lending immediately; no confirmation. Opening the full app is one click.
