# Hildegard
- Owner: Donovan (GitHub baney75). Private project. Named after Saint Hildegard of Bingen (alt name considered: Angelico; Hildegard chosen).
- Goal: open source, self-hosted alternative to Higgsfield, Suno and ElevenLabs. Runs on any device in opportunistic or server mode, with auto activity detection and user-forced priority.
- Scope: transcription and image labeling up through video, music, voice and 3D generation. Easy model install and multi-device clustering on Mac, Windows, Linux, plus an Omarchy plugin.
- Agents connect to the user's GPUs through MCP (image, voice gen etc. as tools, usable by small models too). Donovan wants it "massively powerful". MCP must work in anyone's chatbot with easy linking, fewest clicks, and agents able to set everything up for their owner end to end. Install must be easy for agents too, especially on Omarchy (2026-10-19).
- Remote access (updated 2026-10-19): Tailscale is the shipping option. Hildegard Link (our own e2e-encrypted relay, approved 2026-10-18, doc /mnt/project-files/architecture/mcp-public-link.md) is optional and shown as "coming soon" for now.
- Omarchy (2026-10-19): an installable Omarchy plugin, NOT a theme. Quality bar: 0xSero's Local AI plugin https://plugins.omarchy.org/plugin.html?id=sero.local-ai.
- iOS and Android apps for remote access.
- Optional BYO API keys for outside models, with clear cost tracking. Selling points: savings, privacy, ownership of outputs. Also link Runpod, Colab, Hugging Face compute.
- Priorities (2026-10-16): security, speed/optimization, best-fit languages, design paramount, near-perfectionist care, zero regressions.
