VInstall

Install Hildegard

Pick your computer.

The desktop app

Download it, open it, and follow the steps. No admin rights needed.

Download for Windows

Hildegard_x64-setup.exe 64-bit

Or one line in PowerShell

Also no admin rights. Installs in your home folder.

irm https://dbaney.com/hildegard/install.ps1 | iex
  • The app isn’t signed yet in this pre-alpha, so Windows asks you to confirm. Choose More info, then Run anyway.
  • On Windows, Hildegard renders on NVIDIA graphics cards. AMD support is coming.

The desktop app

Download it, open it, and follow the steps.

Download for Mac

Hildegard_aarch64.dmg Apple silicon

Or one line in Terminal

Works on Apple silicon and Intel Macs. No sudo.

curl -fsSL https://dbaney.com/hildegard/install.sh | sh
  • On a Mac, takes render on another computer’s GPU with NVIDIA or AMD graphics. The models don’t render well on Apple’s GPU yet.
  • The app isn’t signed yet in this pre-alpha, so macOS asks you to confirm. Open System Settings, then Privacy & Security, and choose Open Anyway.

The desktop app

Download it, make it executable, and open it.

Download for Linux

Hildegard_amd64.AppImage x86-64

Or one line in a terminal

Installs in your home folder. No sudo.

curl -fsSL https://dbaney.com/hildegard/install.sh | sh
  • NVIDIA and AMD cards both work on Linux. On Omarchy? There’s a bar widget.

The bar widget

A ring in your bar that fills while a shot renders. Add it, click the ring, and choose Set up Hildegard.

omarchy plugin add https://github.com/baney75/omarchy-hildegard --enable

Or one line in a terminal

The widget finds Hildegard on its own.

curl -fsSL https://dbaney.com/hildegard/install.sh | sh
  • The widget runs no root commands and changes none of your config. Built for Omarchy 4.

Then pick a model

The app walks you through it. In a terminal, it’s two commands.

  1. hildegard setup

    Picks a video model that fits your GPU and links your AI apps.

  2. hildegard open

    Opens the Studio in your browser.

  • Checks every download against a SHA-256 written into the installer.
  • Puts everything in one folder: %LOCALAPPDATA%\Hildegard~/Library/Application Support/Hildegard~/.local/share/hildegard
  • Sets up ComfyUI and PyTorch for your GPU, then starts Hildegard.

VIIThe Choir

Render on another device

A Mac or laptop without a big GPU can render on one of your other computers. Put both on your Tailscale network and install Hildegard on both.

  1. On the computer with the GPU

    hildegard choir invite

    Prints a one-line join code. Treat it like a password.

  2. On the other computer

    hildegard choir join

    Paste the code when it asks. It won’t show on screen.

  3. See it work

    hildegard choir list

    Shots now render there, and the Studio says so. Models installed there count here, so nothing downloads twice.

hildegard choir use local renders here again. In the Studio, Settings, then Devices, does all of this with buttons.

VIIIAgents

Let your AI apps help

An agent can install Hildegard for you. Once it’s running, any AI app you link can direct shots on your GPU.

Set it up with an agent

Claude Code, Codex, Cursor and other AI apps can do it. Paste this into one.

Install Hildegard on this computer for me. Follow https://github.com/baney75/hildegard/blob/main/INSTALL-FOR-AGENTS.md step by step. Ask me before you accept any model license, and never ask me for a token or passphrase.

It shows you each model’s license word for word and asks first. For hosting and devices too, point it at the full guide for agents.

Then direct shots from them

Hildegard is an MCP server. Link an app, and it can direct shots on your GPU.

hildegard connect --all     # every app on this computer
hildegard connect cursor    # or just one
hildegard connect --print   # the config, for any other app

Works with Claude Code, Claude Desktop, Codex, Cursor, OpenCode, VS Code, Windsurf and LM Studio. Each app’s config is backed up before Hildegard adds itself.

IXHost mode

Host your own at a link

Your studio at an HTTPS link, for your phone, your laptop and the people you invite. Everyone signs in. It uses Tailscale, so install it and sign in first.

  1. hildegard host owner

    Choose your name and a passphrase for signing in from other devices.

  2. hildegard host

    Prints your link, like https://my-pc.tail1234.ts.net. Open it anywhere on your tailnet.

  3. hildegard host invite

    A one-time link for someone else to join as a director.

Directors
Make films of their own, which only they and owners see.
Owners
Can do everything: models, devices, people and settings.

The link stays inside your tailnet. hildegard host --funnel puts it on the public internet, so use a long passphrase. hildegard host off turns it off.

XHugging Face

Link Hugging Face, safely

Wan 2.2 downloads without an account. LTX asks you to accept its license on Hugging Face first, so Hildegard needs your account to fetch it.

hildegard hf login

It signs you in with Hugging Face, or asks for a read token at a prompt that doesn’t show what you type. In the Studio, Settings, then Hugging Face, does the same.

  • Kept in your keychain. macOS Keychain, Windows Credential Manager, or the Secret Service on Linux. Without one, a file only you can read.
  • Never on a command line. Never written to ~/.cache/huggingface or shown in your shell history.
  • Never shown to AI apps. If an agent asks you to paste your token into a chat, don’t.

XIQuestions

What people ask first

Is Hildegard a free alternative to Higgsfield?

Yes. Hildegard is a free, open source AI film studio: you direct shots with cameras, lenses, moves and looks, keep takes and export films, as you would in Higgsfield. The difference is where it runs. Every shot renders on your own GPU with open models (LTX-2.5 and Wan 2.2), so there are no credits, no queue behind other people, and nothing leaves your computer.

Can I run something like ElevenLabs on my own computer?

Yes. Hildegard’s voice room speaks in 25 built-in voices, designs new voices from a description, dubs, transcribes and clones voices, all on your GPU, and Kokoro even runs on the CPU. It clones a voice only when its owner reads a fresh consent line aloud, and every clip carries an inaudible watermark.

Is there a local, open source alternative to Suno?

Music is the next room in Hildegard, built on open music models and running on your own GPUs. It isn’t out yet. Today Hildegard makes film, voice, characters and 3D.

What GPU do I need to make AI video locally?

An NVIDIA card with 12 GB of memory runs Wan 2.2 at 720p, and 24 GB or more runs LTX-2.5 with sound at up to 1088p. AMD cards work on Linux. Every film on this page came from one 12 GB laptop GPU. With less, or none, Hildegard renders on another of your computers or on a GPU you rent.

Does Hildegard work on a Mac?

The Studio and the app run on macOS. The video models don’t render well on Apple’s GPU yet, so a Mac sends its shots to one of your computers with an NVIDIA or AMD card, over Tailscale. Voice runs on the Mac itself.

Does anything I make leave my computer?

No. Prompts, takes, voices and films stay on your devices. Hildegard reaches the internet only to download the app and the models you choose, and every shot renders offline after that. If you share your studio at a link, it goes over your own Tailscale network.

Can ChatGPT, Claude or another AI app use it?

Yes. Hildegard is an MCP server, so Claude Code, Claude Desktop, Codex, Cursor, VS Code, LM Studio and others can direct shots, speak lines and run the make-check-improve loop on your GPU. claude.ai and ChatGPT connect through your Hildegard link. One command, hildegard connect --all, links every app on a computer.

Can I use what I make commercially?

What you make is yours. Hildegard itself is AGPL-3.0 and its presets are Apache-2.0. Each model has its own license, shown before it downloads: Wan 2.2, FLUX.2 [klein] 4B and the voice models allow commercial use, and LTX-2 and LTX-2.5 are free for people and companies under $10M in yearly revenue.

How is Hildegard different from ComfyUI?

Hildegard runs on ComfyUI and sets it up for you. On top it adds camera language, films made of shots and takes, a queue, characters, voice, sharing across your computers, a studio at a link for your other devices, and tools for your AI apps. You never have to wire a node graph.

XIIReference

The fine print

Check what you downloadChecksums for the installer

The installer checks every file it fetches against a SHA-256 written into it, and refuses any that don’t match. To check the installer itself first, fetch it with the release’s SHA256SUMS. Once it’s running, hildegard doctor checks every part and prints the command that fixes each problem.

$u = 'https://github.com/baney75/hildegard/releases/latest/download'
iwr "$u/install.ps1" -OutFile install.ps1
iwr "$u/SHA256SUMS" -OutFile SHA256SUMS
(Get-FileHash install.ps1).Hash.ToLower()
Select-String ' install.ps1$' SHA256SUMS
# the two hashes match? then run it
Get-Content install.ps1 -Raw | iex
u=https://github.com/baney75/hildegard/releases/latest/download
curl -fsSLO "$u/install.sh"
curl -fsSLO "$u/SHA256SUMS"
grep ' install.sh$' SHA256SUMS | shasum -a 256 -c
# says OK? then run it
sh install.sh
u=https://github.com/baney75/hildegard/releases/latest/download
curl -fsSLO "$u/install.sh"
curl -fsSLO "$u/SHA256SUMS"
sha256sum --check --ignore-missing SHA256SUMS
# says OK? then run it
sh install.sh
Remove HildegardOne folder, so it’s quick

Everything lives in one folder in your home. Your models and films are in that folder too: export any film you want to keep first. Remove the desktop app like any other app. hildegard disconnect <app> unlinks an AI app.

hildegard hf logout
hildegard stop
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\Hildegard"

Then take Hildegard\bin out of your PATH: search Windows for “environment variables for your account”.

hildegard hf logout
hildegard stop
rm -rf ~/Library/Application\ Support/Hildegard ~/.local/bin/hildegard
hildegard hf logout
hildegard stop
rm -rf ~/.local/share/hildegard ~/.local/bin/hildegard
omarchy plugin remove io.github.baney75.hildegard
rm -rf ~/.local/state/hildegard-omarchy
hildegard hf logout
hildegard stop
rm -rf ~/.local/share/hildegard ~/.local/bin/hildegard

Open, and yours to keep. Model weights are never bundled: Hildegard fetches each one from its publisher, shows you its license and asks before the first download.
