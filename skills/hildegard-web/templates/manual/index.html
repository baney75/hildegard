Getting started

Tern keeps a folder the same on every machine you own, over your own network, with no account and no server in the middle. This page takes about ten minutes: install it, pair two machines, and sync your first folder.

Options you'll use

Every option works on the command line or in tern.toml at the top of the shared folder.

OptionDefaultWhat it does
--ignore.git, node_modulesPatterns to leave out, as in a .gitignore.
--one-wayoffOnly send from this machine; never take changes back.
--limitnoneMost bandwidth to use, such as 5MB/s.
--quiet-hoursnoneHours to pause, such as 09:00-17:00.
--keep30dHow long replaced versions stay in .tern/history.

Before you rely on it

Warning

Sync is not a backup. Delete a file on one machine and it's deleted on all of them. Tern keeps old versions for 30 days, but keep a real backup too.

Tip

If both machines change the same file while apart, Tern keeps both and names the other one report (from studio-mac).md. Nothing is ever silently overwritten.
